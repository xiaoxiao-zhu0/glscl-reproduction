# 已验证实验记录

本目录是本地运行目录中小型结果文件的版本化快照，不包含数据下载包、模型权重或临时压缩包。日志中的路径反映真实运行环境。

- `douban-subset/`：512 用户的真实 Douban 数据子集，CPU 训练 15 轮。
- `server2-trial-20261017/`：服务器 2 的 9 项测试、GPU 小样本训练和一轮非抽样 Douban 数据训练。
- `data-preparation/`：数据来源、固定提交、下载哈希及各版本划分统计。
- `source-search/`：候选官方仓库的 README 和文件树检索快照。

服务器试跑中，训练耗时 42.63 秒，验证耗时 2.25 秒；含验证和检查点保存的单轮为 44.93 秒。完整训练子进程耗时 57.01 秒。正式 100-300 轮训练尚未启动。

这些记录证明代码在所述数据和配置下可以运行，不代表论文完整指标或基线增益已复现。数据版本、划分和实现选择详见项目根目录的 `REPRODUCTION_NOTES.md`。
